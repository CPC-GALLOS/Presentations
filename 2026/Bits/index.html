Herramientas de hoy

Cambio de base

  • n % 2 último bit; n / 2 lo borra
  • vueltas ⌊log2 n⌋ + 1
  • binario → número: n * 2 + bit
  • k bits → 2k valores, máx 2k − 1
  • 2k > todos los de abajo juntos
  • int 231 − 1, long long 263 − 1
  • x << k = x·2k, x >> k = x / 2k
  • bit k = (x >> k) & 1
  • x & (2k − 1) = x % 2k

Operaciones

  • a ^ a = 0, a ^ 0 = a
  • a ^ b = x ⇔ b = a ^ x
  • a + b = (a ^ b) + 2(a & b)
  • a & b ≤ min; AND nunca sube
  • a | b ≥ max
  • x & (x − 1) quita el 1 más bajo
  • xor(l..r) = px[r] ^ px[l−1]
  • ~x = −x − 1
  • x & −x = el 1 más bajo
